What is Query Expansion?

Query Expansion is the process of adding related terms to a user's original search query.


  • Users often enter short queries.
  • The original query may not contain enough information.
  • Related terms can help find more relevant documents.
Original Query

car accident
↓
Expanded Query

car automobile accident collision

Why Do We Need Query Expansion?

The Vocabulary Problem

Users and documents may use different words for the same concept.

User Query:
heart attack treatment
Document:
myocardial infarction management

Query Expansion Helps With

  • Synonyms
  • Different terminology
  • Short or incomplete queries
  • Vocabulary differences between users and documents
The goal is to reduce the vocabulary gap.

Pseudo-Relevance Feedback

Basic Idea

The system assumes that the top few retrieved documents are relevant and uses them to improve the query.


It does not ask the user for feedback. The system automatically selects useful terms.

User Query

car accident
↓
Top Documents

vehicle · collision · driver · road
↓
Expanded Query

car accident vehicle collision driver

WordNet-Based Query Expansion

Basic Idea

WordNet is a lexical database that stores relationships between English words.


  • Synonyms
  • More general terms
  • More specific terms
User Query

car
↓
Related Words

automobile · auto · motorcar
↓
Expanded Query

car OR automobile OR auto
07 / 10

Embedding-Based Query Expansion

Basic Idea

Embedding models represent words or sentences as numerical vectors.


Terms with similar meanings tend to have similar representations.


This allows the system to find semantic relationships rather than relying only on exact words.

User Query

laptop repair
↓
Semantically Related

computer troubleshooting
notebook repair
laptop maintenance
↓
Expanded Query

laptop repair computer troubleshooting

Conclusion

  • Query expansion improves retrieval by adding useful terms.
  • PRF learns from initial search results.
  • WordNet uses predefined word relationships.
  • Embeddings find semantically related concepts.
  • Modern search systems increasingly combine traditional IR + semantic methods.
The goal is not simply to retrieve more documents,
but to retrieve more relevant documents.
