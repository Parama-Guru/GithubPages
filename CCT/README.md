# CCT: Confusion-Calibrated Tutoring

**NIT Hackathon / 2027**

Published URL: https://parama-guru.github.io/GithubPages/CCT/

Open [index.html](index.html) in a modern browser. This is a nine-slide static pitch deck, not the tutoring application's backend. No Node.js, dependency installation, account, or server is required to view it.

For local sharing, keep [index.html](index.html), [styles.css](styles.css), and [script.js](script.js) together. Google Fonts are fetched when online; fallback fonts work without that connection.

## Navigation

- Use the previous/next buttons, arrow keys, Page Up/Down, or horizontal swipes.
- Desktop slide dots jump directly to a slide. Home/End select the first/last slide when a control is not focused.
- Long slides scroll vertically without the mouse wheel accidentally switching slides.
- Wide comparison tables scroll within their own area on narrow screens.
- Press F for browser fullscreen where supported.
