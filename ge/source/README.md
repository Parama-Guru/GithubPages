# Ganesh Electricals — 3D website source

Source for the site published at `GithubPages/ge/` (`https://parama-guru.github.io/GithubPages/ge/`).
Content comes only from the original site (`src/content/site.json`, `src/content/organisation.ts`).

## Commands

```powershell
npm ci                    # install (Node 24)
npm run dev               # http://127.0.0.1:5173/GithubPages/ge/
npm run assets            # regenerate Blender models (needs Blender 4.5 LTS; set BLENDER=path\to\blender.exe)
npm run media             # favicon, touch icon and loader emblem from the original logo
npm run build             # typecheck + client build + prerender every page into dist/
npm run serve             # serve dist/ at http://127.0.0.1:4173/GithubPages/ge/ (gzip, like Pages)
npm run posters           # with `serve` running: render fallback posters and social images from the 3D scene
npm run publish:local     # copy dist/ into GithubPages/ge/ (keeps source/ and checklist.md)
npm run test:unit         # Vitest: camera maths, routes, content integrity
npm run test:e2e          # Playwright + axe: pages, 3D journey, clicks, navigation, fallbacks, budgets
npm run lint
```

After changing the scene, run `build`, `serve`, `posters`, then `build` again so the posters are included.

## Structure

| Path | Purpose |
|---|---|
| `src/content/` | Original company content and the organisation chart |
| `src/routes/routes.ts` | Clean URLs, titles, descriptions, zones |
| `src/ui/` | HTML templates shared by the prerender and the client router |
| `src/app/` | Motion (Lenis + GSAP), home journey, page controller, preferences, sound |
| `src/world/` | Three.js runtime: camera path, zones, materials, textures, shaders, post-processing |
| `blender/build_assets.py` | Switchgear, transformer, insulator string and lattice tower models |
| `tools/` | Prerender, publish, static server, Blender/asset build, poster and screenshot tools |
| `tests/` | Unit and browser tests |

## Assets

All 3D models are generated by `blender/build_assets.py` (own work). Textures, signs, screens and the
organisation board are drawn in code. Photographs, logos and client logos are from the original website.

## Known limitations

- GitHub Pages serves a custom 404 and `robots.txt` only from the repository root; `ge/404.html` is used for
  in-site navigation, and `sitemap.xml` can be submitted to search engines directly.
- Frame rate on real phones has not been measured on physical devices; the site lowers quality automatically
  when frames are slow.
